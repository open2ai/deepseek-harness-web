# DeepSeek Harness Web

> 在 VS Code 里直接用本地 dsh——不用切浏览器，侧边栏即可对话。

本插件是 **DeepSeek Harness（dsh）** 的一个轻量适配：通过复用官方同一套协议接入本地 dsh，完全不修改 dsh、不新增密钥、数据只发本机。在 VS Code 侧边栏即可对话，选中代码可处理 / 提问 / @，支持图片、文件与消费记录。它自动探测端口/能力并自动启动服务，协议耦合集中、升级较易跟进。它只覆盖 dsh 的常用子集，完整功能请用 dsh 原生 Web 端。

> ⚠️ **重要说明**
>
> 本插件只是**基于 dsh 能力做的一个轻量适配**，实现了对话等**常用功能**，用于在 VS Code 里快速集成使用。
>
> - **完整功能请使用 dsh 原生 Web 端**（面板里「在本地打开」即可进入）。插件不保证覆盖 dsh 的全部能力，也不保证与 dsh 网页完全一致。
> - 本插件随 dsh 的版本**持续适配**，但始终只覆盖常用子集，**不保证**与所有 dsh 版本完全兼容；dsh 升级后个别功能可能变化或失效，届时请以 dsh 原生端为准。
> - 插件**不修改 dsh 任何东西**，数据只发往本机 dsh 服务；如遇任何异常，优先以 dsh 原生 Web 端的结果为准。


## 快速开始

1. 安装 Node.js（22.19+）
2. 在 VS Code 安装本插件
3. 点左侧 Activity Bar 的 **DSH 图标**，侧边栏出现聊天面板，直接对话

首次使用时会自动启动 dsh 服务。

## 要求

- 当前支持平台：VS Code
- Node.js 22.19+（或 24+）
- VS Code 1.107.1+（兼容 sidex/Trae）

## 版本兼容

## 常见问题

- **想让官方网页/聊天更省内存？** 关闭 `dsh.retainContextWhenHidden`：切走释放界面、切回重新加载；记录不丢，但当前会话需到「工作区」重新点开。默认开启=切回保留原状态。
- **某功能在网页有、插件里没有？** 这是正常的——插件只是适配了常用子集，请用 dsh 原生 Web 端（「在本地打开」）。
